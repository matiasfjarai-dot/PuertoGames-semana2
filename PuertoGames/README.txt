PUERTOGAMES - Semana 2 - Desarrollo Orientado a Objetos I

Proyecto Java simple con paquetes model y app.

Para abrir en IntelliJ IDEA:
1. Descomprime PuertoGames.zip.
2. En IntelliJ IDEA, selecciona File > Open y abre la carpeta PuertoGames.
3. Si IntelliJ solicita configurar el JDK, selecciona un JDK instalado (17 o superior funciona).
4. Abre src/app/Main.java y pulsa Run sobre el metodo main.

Clases:
- model/Direccion.java: representa una direccion.
- model/Cliente.java: representa un cliente con direccion creada internamente (composicion).
- app/Main.java: crea y muestra un cliente de ejemplo.
